# 건네주는 프롬프트 ① — 공부·전달용 인터랙티브 교과서 (도구 없이)

> 쓰는 법: 아래 상자 전체를 복사해 Claude(claude.ai 또는 Claude Code)에 붙인다. `[ ]` 세 칸만 채운다.
> Claude Code 이고 GitHub 에 로그인(`gh auth login`)돼 있으면 배포까지 한다. claude.ai 면 HTML 파일까지 만든다.

```text
주제: [예: 산염기 평형]
읽을 사람: [예: 나 자신 / 생리학을 안 배운 친구]
끝나면 답할 수 있어야 하는 질문 3개: [예: 왜 과호흡하면 손이 저린가 / …]

https://books.euiyun.com/ 의 인터랙티브 교과서 방식(예: https://bodybook.euiyun.com/ 의 한 장)을 «구조만» 본떠
위 주제의 웹 교과서를 만들어 줘. 그 사이트의 글·그림·이름·로고는 쓰지 말고 새로 써.

순서
1. 먼저 목차만 보여 줘: 장 3~6개, 장마다 «시뮬레이터가 답할 질문» 목록. 내가 승인하면 1장만 만들고, 확인받은 뒤 나머지.
2. 쓰기 전에 출처(교과서 장, 지침, 리뷰 2~4개)를 정하고, 페이지의 모든 숫자를 그 출처와 짝지은 표를 따로 줘.
   기억으로 쓴 숫자, 지어낸 참고문헌은 안 된다. 문헌은 PMID나 DOI 를 달아.

시뮬레이터 규칙
- 질문 하나에 시뮬레이터 하나, 컨트롤 1~4개. 질문이 없는 장식 위젯은 만들지 마.
- 값을 끝까지 밀면 무너지는 모습(포화, 역전, 경고색)이 보이게.
- 슬라이더보다 캔버스를 직접 끄는 조작을 우선. 캔버스 안에 축 이름·단위·핵심 숫자를 그려서 그림만 봐도 이해되게.
- 결과 숫자 옆에 정상 참고값. 시뮬레이터 아래 「해볼 것: ① ② ③」과 모델의 가정 한 줄.

장의 순서: 일상의 질문 → 직관 → 시뮬레이터 → 원리(수식은 꼭 필요할 때만, 기호마다 단위·대표값) → 실제 수치 → 핵심 정리 3~5줄 → 확인 문제 3~5개.

문장
- 평서문 «~다», 짧게. 시뮬레이터 앞뒤로 2~4문장. 이모지 금지.
- 이런 말버릇은 쓰지 마: 수사형 제목, 「A가 아니라 B」, 「~의 핵심은」, 「놀랍게도」, 비유로 설명 대신하기, 앞 문단 되풀이.
- 용어는 처음 나올 때 한글(English) + 한 문장 풀이.

만들기
- 정적 사이트(HTML+CSS+JS, 빌드 없음). 다크 모드, 휴대폰 390px 폭에서 가로 넘침 없음.
- 만든 뒤 모든 슬라이더를 최소·최대로, 모든 버튼을 눌러 콘솔 오류가 없는지 확인하고 결과를 말해 줘. 안 해 본 것은 안 해 봤다고.
- 배포: GitHub Pages(공개). 저장소 이름과 올라갈 파일 목록을 먼저 보여 주고 내가 «올려»라고 하면 올려.
  강의안·교재 PDF, 출처가 불분명한 이미지는 올리지 마. footer 에 출처 목록과 「시뮬레이터 수치는 교육용 근사」.
```
