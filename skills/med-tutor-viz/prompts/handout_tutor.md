# 건네주는 프롬프트 ② — 본과 시험 대비 «빠른 한 장» (도구 없이)

> 쓰는 법: 강의안 PDF(있으면 족보도)를 첨부하고, 아래 상자를 복사해 붙인다. `[ ]` 만 채운다.
> claude.ai 면 결과 HTML 을 내려받아 휴대폰·PC 브라우저로 연다. 공개 사이트에 올리지 않는다.

```text
과목·강의: [예: 신장 — 산염기 장애]
시험까지: [예: 4일]
첨부: 강의안 PDF [+ 족보]

이 강의를 30분 안에 잡을 «인터랙티브 한 장»(HTML 파일 하나)을 만들어 줘. 시간이 제일 중요하다.

1. 족보가 있으면 반복해서 묻는 개념·수치·감별을 세어 상위 5~8개를 «시험 축»으로. 없으면 강의안에서 표·굵은 글씨·그래프로 강조한 것.
   시작 전에 그 축 목록과, 시뮬레이터마다 「무엇을 바꾸면 → 어느 값이 → 어느 쪽으로(강의안 쪽수)」 표를 보여 줘
   (질문은 하지 말고 바로 이어서 만들어).
2. 축마다 표현:
   - 그래프를 읽는 문제 → 시뮬레이터(값을 끝까지 밀면 그래프가 어떻게 무너지나). 0~4개. 강의안에 곡선·식·수치가 없는 개념 강의면 0개.
   - 비슷한 것 감별 → 나란히 비교 표, 다른 칸만 색칠. 1~3개.
   - 경로·순서 → 누르면 다음 단계가 켜지는 도식.
   - 외울 수치 → 숫자 상자. 시뮬레이터로 만들지 마.
3. 순서: 이 강의가 답하는 질문 한 줄 → 시험 축 → 헷갈리는 것 → 족보형 문제 5개(해설에 «왜 오답인가») → 시험 직전 30초 정리 5줄.

규칙
- 정답 기준은 강의안이다. 교과서와 다르면 강의안 값을 쓰고 작은 글씨로 「교과서는 ~」. 수치마다 강의안 쪽수를 footer 에.
- 족보 정답을 모르면 지어내지 말고 「정답 확인 필요」.
- 강의안에 없는 수치를 화면에 내지 마(양 끝값만 있으면 중간값을 만들지 말고, 범위 밖으로 늘리지도 마). 쪽수를 못 다는 방향은 시뮬레이터로 만들지 말고 확인할 목록으로.
- 강의안 그림을 그대로 넣지 말고 새로 그려(SVG).
- 문장은 짧은 평서문, 한 문단 3줄 이하. 「~의 핵심은」「A가 아니라 B」 같은 말버릇 금지. 용어는 시험지 표기대로 한글(영문).
- 휴대폰 390px 에서 그래프 글자가 읽히게. 다크 모드.
- 시뮬레이터 하나가 잘 안 돌면 오래 붙잡지 말고 정적 그림으로 바꿔.
- 다 만들면 모든 슬라이더·버튼을 눌러 오류가 없는지 확인하고, 위 방향 표의 줄마다 실제로 조작해 나온 숫자를 옆에 적어 줘.
  표와 다르게 움직이는 것이 있으면 고치고, 안 해 본 것은 안 해 봤다고 말해 줘. 오류가 없다고 맞는 것은 아니다.
```
